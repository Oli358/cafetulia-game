## Traspaso para continuar en casa

### Arrancar

Si el repo ya existe en casa:

```bash
git fetch origin
git checkout home/menu-cafe-3d
git pull origin home/menu-cafe-3d
npx pnpm install
npx pnpm dev
```

Si hay que clonarlo:

```bash
git clone https://github.com/Oli358/cafetulia-game.git
cd cafetulia-game
git checkout home/menu-cafe-3d
npx pnpm install
npx pnpm dev
```

- Hace falta **Node 22.5+** (recomendado 24 LTS); el servidor usa `node:sqlite`.
- Abrir <http://127.0.0.1:3000>. Si `localhost` falla por IPv6, usar `127.0.0.1`.
- La URL de Cloudflare del móvil era temporal y **no funcionará desde casa**.
- Las tres imágenes `fichas1.webp`, `fichasdecerca.webp` y `todaslasfichas.webp` siguen sin seguimiento; son del usuario y no se han tocado.

### Dónde se quedó

- Portada con vaso 3D, tres mundos y rueda simétrica (un tick arriba vuelve al póster, un tick abajo abre el menú).
- Lobby con mesa 2D, ingredientes de fondo y fondo de bar.
- Partida con **tabla de la casa**:
  - Móvil: rejilla **2×2** con los 4 jugadores a la vez, sin slider horizontal.
  - PC: lista vertical flotante arriba a la izquierda; el tablero conserva el centro exacto del ancho completo.
  - Cada jugador muestra avatar, nombre, fichas en mano y **desglose de monedas 10/5/1 + total**.
  - Glow animado en el jugador con el turno.
  - Bolsa destacada con icono, contador `X / 100` y barra de progreso.
  - El vuelo de monedas usa el `CoinTray` de la tabla (`data-player-tray`), tanto en móvil como en PC.
- Popovers anclados a su botón en todos los tamaños, con animación de 0,24 s.
- Fondo de bar en partida y lobby (`public/backgrounds/cafe-bar.jpg`, 67 KB).
- Aviso «Gira el teléfono» en móvil horizontal; manifest PWA en `portrait` y service worker v14.
