# Referencias del tablero

Fotos **reales** del tablero físico, aportadas por el usuario. No son imágenes generadas.

- `tablero-real-sin-fichas.png` — tablero vacío; es la referencia principal para transcribir las 24 mesas y las 68 sillas.
- `tablero-real-con-fichas.jpg` — partida en curso; útil para ver la barra, las fichas y el flujo de juego.

## Notas importantes

- El tablero tiene **24 mesas y 12 países, 2 mesas por país**.
- Las **etiquetas y banderas impresas no son fiables**: por ejemplo, aparece “CANADÁ” donde debe ser Inglaterra. Se ignoran los nombres impresos cuando no coincidan.
- Se usarán los **12 países oficiales** (África, Alemania, China, Cuba, España, Estados Unidos, Francia, India, Inglaterra, Italia, Rusia y Turquía), mapeados por la **posición** de cada mesa.
- Estas fotos son referencia de **topología y estilo**; no se usarán como textura final del tablero.
