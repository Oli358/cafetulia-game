# apps/web — Cliente

Cliente del juego: **Vite + React + TypeScript + React Three Fiber + Tailwind CSS**.

**Estado:** pendiente de implementación.

## Contenido previsto

- `src/scene/` — tablero 2.5D, fichas, sillas, mesas, barra, cámara y luces.
- `src/ui/` — portada, lobby, partida, final, reglas, ajustes.
- `src/state/` — Zustand y sincronización con el servidor.
- `src/i18n/` — textos en español (inglés más adelante).
- `public/` — assets optimizados (tablero, retratos, sonidos, iconos PWA).

Ver [`docs/ARQUITECTURA.md`](../../docs/ARQUITECTURA.md) y [`docs/ARTE.md`](../../docs/ARTE.md).
