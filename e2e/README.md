# e2e — Pruebas end-to-end

Pruebas con **Playwright** sobre la aplicación real.

**Estado:** pendiente de implementación.

## Contenido previsto

- `lobby.spec.ts` — crear sala, unirse por código, elegir opciones.
- `game.spec.ts` — partida completa de 2–4 jugadores.
- `reconnect.spec.ts` — desconexión, reconexión y expulsión.
- `mobile.spec.ts` — viewport móvil y PWA.
- `visual.spec.ts` — capturas de pantallas clave.

Se ejecutan en CI contra un servidor de pruebas.
