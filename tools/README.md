# tools — Herramientas

Scripts de apoyo para datos y assets.

**Estado:** pendiente de implementación.

## Contenido previsto

- `board-import/` — transcribir el tablero desde la foto de referencia a `board.json`.
- `assets/` — optimizar imágenes, generar atlas y comprimir modelos.
- `cards/` — generar las 28 cartas y sus variantes.
- `seed/` — datos de ejemplo para desarrollo y tests.

Nada de esto forma parte del juego en producción; son utilidades de desarrollo.
